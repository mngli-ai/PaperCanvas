# GUI validation from repository checkout

Standalone skill scripts do not require Electron. If the PaperCanvas repo already has dependencies installed, run npm run build, then start a distinct Electron instance with PAPER_CANVAS_TEST_PROFILE pointing to a new artifacts/ subdirectory and --remote-debugging-port=9350. That profile needs workspace.json with {"rootPath":"<absolute temporary workspace>"}. Never use the default user profile. Use node scripts/skill-ui-smoke.mjs <generated.papercanvas.json> <screenshot-directory> 9350 to load only this isolated profile, visit every canvas through tree, verify element counts and centered deletion controls, save screenshots. The smoke helper changes the isolated profile autosave; never point it at a user's live instance. This helper is repo-only, not bundled standalone. For manual verification open generated file in isolated instance, enter each module then return; inspect text, arrow attachment and playback with single-step into. No GUI: report structural-only status.
