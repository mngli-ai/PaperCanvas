# 多轮代理试用与回调记录

## Round 1：图像生成服务
独立子智能体先读取 SKILL.md，创建5画布/3层/24节点/23箭头/5路线的中文架构 spec。初次包内脚本尚未齐全，按规则报告 MODULE_NOT_FOUND，没有自编替代品。补齐脚本后真实失败为 `Canvas creation_overview: edge cycle`：把合法采样反馈环误判成 child 层级循环。

回调：明确 child 必须无环、数据流可循环；生成器对有环数据流采用稳定节点序并将反馈边走侧边通道；加入回归测试。修复后同一输入 build/check valid true。主控在隔离 Electron profile 逐个进入全部5个画布，保存截图与图元数量报告；总览截图确认反馈箭头、正文无严重遮挡。

## Round 2：科研检索助手
另一子智能体读取修订版 skill，生成不同主题的6画布/4层/30节点/29箭头/6路线架构，含中文长标签和分支汇合。独立生成检查通过，主控复验 check valid true，并在隔离窗口进入全部6个画布。截图显示文字可见、箭头不穿正文；顶部标题靠近原生操作提示、部分长词断行不自然、纵向双输入可能误导并行语义。

回调：补充中文主动换行、纵向布局限制、职责明确命名、顶部视口安全区、无边标签与无自动并列布局的边界。不把估算 check 当视觉验证。

## 总体验证
全仓66项测试通过、typecheck/build通过。删除按钮实测24×24px，align-items/justify-content center。新 skill 脚本复制到临时独立目录后运行的自动测试通过，证明无项目依赖。

结构检查器仅覆盖本生成器的rectangle/text/arrow子集。GUI自动化验证了所有画布进入、图元装载、按钮布局；并未逐个点击11条路线播放按钮，跨层路线执行由runner既有单元测试保障，不宣称全量人工演示验收。示例不是论文复现或实测系统。实际截图和原始过程日志保留本机artifacts，不打包用户本机信息。
